# Shared UI Component Library (`@repo/ui`)

A reusable, accessible React component library shared across the RupeeOne Wallet monorepo, styled with **Tailwind CSS v4**.

## 🏛 Overview

This package encapsulates UI building blocks used across the wallet dashboard, authentication screens, and payment cards.

All components are written in **TypeScript** and **React**, with full type definitions exported for consuming applications.

---

## 🧩 Component Catalog

### 1. `Appbar`
Top navigation header showing brand title, login/logout buttons, and user session status.

```tsx
import { Appbar } from "@repo/ui/Appbar";

<Appbar
  user={session?.user}
  onSignin={() => signIn()}
  onSignout={() => signOut()}
/>
```

- **Props**:
  - `user`: `{ name?: string | null, email?: string | null, image?: string | null } | null`
  - `onSignin`: `() => void`
  - `onSignout`: `() => void`

---

### 2. `Card`
A styled card container with a prominent border and header.

```tsx
import { Card } from "@repo/ui/AddMoneyCardComponents";

<Card title="Transfer Funds">
  <div>Card content goes here...</div>
</Card>
```

- **Props**:
  - `title`: `string`
  - `children`: `React.ReactNode`

---

### 3. `Button`
An interactive button with clean hover and border states.

```tsx
import { Button } from "@repo/ui/AddMoneyCardComponents";

<Button onClick={() => handleSend()}>
  Send Money
</Button>
```

- **Props**:
  - `onClick`: `() => void`
  - `children`: `React.ReactNode`

---

### 4. `TextInput`
A form input field with an integrated label.

```tsx
import { TextInput } from "@repo/ui/AddMoneyCardComponents";

<TextInput
  lable="Amount"
  placeholder="₹ 500"
  onChange={(val) => setAmount(val)}
/>
```

- **Props**:
  - `lable`: `string`
  - `placeholder`: `string`
  - `onChange`: `(value: string) => void`

---

### 5. `Select`
A styled native dropdown selector.

```tsx
import { Select } from "@repo/ui/AddMoneyCardComponents";

<Select
  options={[
    { key: "HDFC", value: "HDFC Bank" },
    { key: "AXIS", value: "Axis Bank" }
  ]}
  onSelect={(val) => setBank(val)}
/>
```

- **Props**:
  - `options`: `{ key: string, value: string }[]`
  - `onSelect`: `(value: string) => void`

---

### 6. `Center`
A layout utility that centers its children both vertically and horizontally.

```tsx
import { Center } from "@repo/ui/AddMoneyCardComponents";

<Center>
  <div>Centered content</div>
</Center>
```

## 📦 How to Use in Applications

Install `@repo/ui` in your application's `package.json`:

```json
{
  "dependencies": {
    "@repo/ui": "*"
  }
}
```

Import components either individually or from the barrel export:
```tsx
import { Appbar } from "@repo/ui/Appbar";
import { Card, Button, TextInput, Select, Center } from "@repo/ui/AddMoneyCardComponents";
```

## 🎨 Tailwind CSS v4 Integration

Because Tailwind CSS v4 uses CSS-first configuration, consuming applications scan `@repo/ui` components by adding the `@source` directive in their main CSS file (e.g., `apps/user-app/app/globals.css`):

```css
@import "tailwindcss";
@import "@repo/tailwind-config";

/* Tell Tailwind to scan @repo/ui components */
@source "../../../packages/ui/src";
```

This ensures utility classes used inside `@repo/ui` (such as `justify-between`, `flex`, `p-4`) are automatically generated by the consumer's Tailwind compiler without requiring separate precompiled CSS builds during local development.

## 🛠 Available Scripts

Run these inside `packages/ui`:

| Command | Action |
|---|---|
| `npm run build:components` | Compiles TypeScript components to `dist/` |
| `npm run build:styles` | Builds standalone CSS bundle using Tailwind CLI |
| `npm run dev:components` | Watches components and rebuilds on change |
| `npm run dev:styles` | Watches and rebuilds standalone CSS |
| `npm run check-types` | Type-checks the package without emitting files |
